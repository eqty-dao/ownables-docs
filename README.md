# Ownables Documentation

Ownables are programmable digital assets that represent ownership, behavior, and lifecycle together.

This documentation is written as a path from practical basics to protocol details.

## Learning path

1. Start with [SDK](01-sdk/README.md) if you want to set up the wallet flow and build your first Ownable.
2. Continue with [Concepts](02-concepts/README.md) for the mental model.
3. Use [Contract Development](03-contract-development/README.md) to build and test contracts.
4. Read [Hub](04-hub/README.md) for authority and locking flows.
5. Use [Integration](05-integration/README.md) for library-level integration in products.
6. Finish with [Protocol](06-protocol/README.md) for exact rules and validation boundaries.

## What this docs set covers

- User-level setup with SDK, wallet flows, and in-browser builder.
- Contract development with ownable-std.
- Hub architecture and operational behavior.
- Integration libraries from `ownables-js`.
- Protocol rules for event chains, external events, and verification.
